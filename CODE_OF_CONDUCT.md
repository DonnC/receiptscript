# Code of conduct

ReceiptScript follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful and constructive. Critique ideas and code, not people.
- Welcome newcomers and questions, whatever someone's experience level or background.
- Harassment, personal attacks, discriminatory language and publishing others' private information
  are not tolerated.

This applies in issues, pull requests, discussions and any other project space.

## Reporting

Report unacceptable behaviour to the maintainer, [@DonnC](https://github.com/DonnC), privately, for
example by email to the address on that GitHub profile. Reports are handled confidentially. The
maintainer may remove comments, lock threads, or block participants who break this code, as described
in the Contributor Covenant's enforcement guidelines.
