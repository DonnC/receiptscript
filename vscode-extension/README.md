# ReceiptScript for VS Code

Write `.rct` receipts with syntax highlighting, completion, hover documentation,
shared engine diagnostics, and a live side-by-side preview. Templates and sample
JSON stay local. Codes are encoded offline; webview scripts are disabled.

## Install

From the repository root:

```sh
npm ci
npm run package:extension
```

In VS Code, open the Command Palette with **Ctrl+Shift+P**, select
**Extensions: Install from VSIX**, and choose `artifacts/receiptscript.vsix`.
Reload VS Code when prompted. The Marketplace release is not yet published.

## Preview

Place `sale.rct` and `sale.preview.json` in the same directory. Open the `.rct`,
then run **RCT: Open Preview** from the Command Palette or editor title button.
The preview follows changes to the open template and JSON sample, plus saved
changes to referenced fragments and images. Invalid source or data shows an
actionable error in the preview instead of a guessed receipt.

`use header "merchant"` resolves `merchant.rct` beside the open template. Image
references are local paths relative to that directory; `asset:` is accepted as a
prefix. PNG, JPEG, GIF and WebP are supported, up to 5 MiB. Absolute paths,
references leaving the directory and remote URLs are rejected by this preview.

Open `examples/receipt-showcase/showcase.rct` in the repository for a complete
sample, or `examples/barcodes/barcodes.rct` for all supported barcode formats.
Preview uses the same engine as the JavaScript package. Physical printer output
depends on adapter fonts, printable width and supported hardware features.

## Development

Run `npm run build` at the repository root, then open this folder in VS Code.
Use **Run > Start Debugging** to launch the Extension Development Host. If F5 is
mapped to a multimedia key on your keyboard, use the menu or Fn+F5.

The extension uses compiled bundles from `../packages/core`, generated by the
root build script. Do not edit `dist`. `npm test` at root tests the core and
extension and rebuilds those bundles first.
