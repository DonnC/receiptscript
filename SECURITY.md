# Security

Report vulnerabilities privately through the repository host's private security
reporting feature when enabled, or through a maintainer's verified contact listed
on the project profile. Do not include customer data or credentials in public issues.

Only the latest maintained release receives fixes during this pre-1.0 phase.
Templates are data, but they can request large outputs and access properties
present in context. Hosts must constrain input sizes and supply safe receipt DTOs.

The core performs no file/network/device I/O. The VS Code preview confines local
references to the template directory, disables webview scripts and encodes codes
locally. HTML image resolvers are explicit host integrations and may return network
URLs; the host is responsible for URL policy and any resulting requests.

Masking filters affect output, not the safety of the underlying context. Do not
pass secrets, retain raw card data in fixtures, or log transaction context.
