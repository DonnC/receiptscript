# Changelog

## 0.3.0 - Unreleased

- Extract independent JavaScript and Kotlin builds from the POS repository.
- Add `ReceiptScript.compile`, named templates, resolved receipts and generic adapters.
- Add strict binding and table-shape validation while retaining low-level APIs.
- Implement offline HTML QR/barcode rendering and wrapped text tables.
- Support Code 128, Code 39, EAN-13, EAN-8, UPC-A and ITF format identifiers.
- Reuse the shared engine for VS Code preview and diagnostics.
- Add TypeScript declarations, local integration examples, CI and release guidance.
- Preserve large integral amounts during Kotlin money formatting and correct missing map/index resolution.
- Add the per-block `ReceiptDriver` interface and Android-first getting-started guide.
- Ship optional ESC/POS portable/desktop profiles, plain-text output, local raster QR/barcodes, image conversion and stream/TCP connections.
- Add compiled Kotlin driver examples and Android asset/Bluetooth-stream/USB/Bitmap examples.
- Add versioned core/driver and source JAR distributions with checksums and a packaged-JAR consumer verification.
- Add a compact product README, node/use-case reference, banner, vector logo and reproducible example media.
